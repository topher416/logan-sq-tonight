# Logan Square Tonight

## What We're Building

A nightly primer for a small friend group (~10-20 people) on what's happening within walking distance of Lyndale & California in Logan Square. Two parts:

1. **Daily SMS push (~4-5pm):** A short, curated text summarizing tonight's events — music, comedy, DJs, specials, anything notable. Hits your phone with zero friction.

2. **Mobile-first website:** The "deep browse" — full event listings by date, venue info, and a stable restaurant/bar directory for the neighborhood. Pull it up when you want to plan ahead or see more detail.

## Why This Approach

- **SMS over Discord/Slack** because it just works — no app to install, no channel to check. A text saying "Jazz trio at Whistler 8pm / Karaoke at Mustache 10pm" is the kind of thing people actually act on.
- **Site over app** because a mobile web page is shareable, bookmarkable, and free to host. No App Store friction for 15 friends.
- **Scraper + LLM pipeline** because these venues don't have APIs — their events live on Squarespace calendars, WordPress posts, Do312 listings, and Instagram. An LLM (Claude Haiku) is the cheapest, most flexible way to extract structured data from messy HTML.

## Key Decisions

- **Scope: Walking distance from Lyndale & California.** Core block is California to Kedzie on Milwaukee Ave. Expanded radius ~1 mile. Not trying to cover all of Chicago.
- **Events are the dynamic layer.** Scraped 1-2x daily from venue sites, Do312, ticketing platforms. This is the hard part and the core value.
- **Restaurants are the static layer.** A curated directory of walkable spots with hours, vibe, price range. Updated manually as needed. Special food events (pop-ups, happy hours, prix fixe nights) get surfaced alongside venue events.
- **SMS via Twilio.** Group text to opted-in phone numbers. Cost ~$3-5/month. Summary generated by LLM from that day's event data — keeps the tone casual and useful.
- **Site on Vercel free tier.** Static frontend reading from a JSON file or lightweight API. Prototype already exists as a React component.
- **Low-key vibe.** This isn't a polished product — it's a neighborhood tool. Design should feel like a friend's recommendation, not a ticketing platform.

## Content Layers

### Layer 1: Nightly Events (Dynamic — Scraped)
- Live music, DJs, comedy, karaoke, trivia, film screenings, literary events
- Source: venue websites, Do312, ticketing platforms, Resident Advisor
- Schema and scraping architecture already defined in milwaukee-ave-tonight-research.md

### Layer 2: Restaurant Directory (Static — Curated)
- Walkable restaurants and food spots near the core block
- Fields: name, address, cuisine, vibe (one-liner), price range, hours, days closed, outdoor seating, reservations needed?
- Hours/closure info needs to stay current — some spots close often or have irregular schedules
- Updated manually — maybe monthly or when something opens/closes
- No scraping needed for the base directory

## Architecture Summary

```
Scraper (Python, cron 2x daily)
  -> Claude Haiku extracts events from HTML
  -> Normalized to event schema (JSON)
  -> Merged with static restaurant directory
  -> Written to events.json / restaurants.json

Site (React on Vercel)
  -> Reads JSON files
  -> Daily view, weekly view, restaurant directory
  -> Mobile-first, shareable URL per date

SMS Push (Python, cron ~4-5pm daily)
  -> Reads today's events from JSON
  -> Claude Haiku generates casual summary
  -> Twilio sends to opted-in numbers
```
